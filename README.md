# COVID-19 India Data Analysis & Visualization

Streamlit dashboard for the Week 6 Data Analytics Internship project by Yash Vijay.

## Dashboard features

- Date-range filtering
- COVID-19 case trend
- Death and recovery trends
- Recovery, mortality and active rates
- Vaccination progress
- Descriptive cases-vs-vaccination comparison
- Key findings
- Filtered CSV download

## Files

- `app.py` — Streamlit application
- `COVID_India_Master_Analysis.csv` — project dataset
- `requirements.txt` — Python dependencies

## Run locally

```bash
pip install -r requirements.txt
streamlit run app.py
```

## Deploy

This project is designed for Streamlit Community Cloud. Connect the GitHub repository, choose `app.py` as the main file, and deploy.
